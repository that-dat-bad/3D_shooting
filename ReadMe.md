## 1. 必須内容 (61点) - 【実装済み】

### Grayscaleを利用したシーン描画
輝度（Luminance）変換を行い、シーン全体のモノクロ（グレースケール）描画を実現しています。

* **実装内容**:
  * 輝度計算式 `dot(color.rgb, float3(0.2125, 0.7154, 0.0721))` により輝度値を算出し、完全モノクロ化および任意のカラー着色に対応。
  * 抽出色以外の非対象領域をモノクロ（グレースケール）に脱色するパートカラー表現にも対応。
* **ゲーム作品での利用**:
  * ナイトビジョン（NVD）モード時の輝度ベース描画、ゲーム演出時のカラーフェード・モノクロ表現、およびデバッグ用エフェクト切り替えとしてゲームシステムに直接統合されています。

## 2. 加点要素 - 【実装済み】

ゲーム作品内に動的演出およびゲームシステムとして組み込まれたポストエフェクト一覧です。

### ① Vignetting (3点) - 【実装済み】
* **ゲーム作品での利用**: 機体の高G旋回時（Gフォースシミュレーション）における視界狭小化（ブラックアウト / レッドアウト演出）として動的に適用。

### ② BoxFilter (3点) - 【実装済み】
* **ゲーム作品での利用**: 指定カーネルサイズ（3x3, 5x5等）の周辺ピクセル平均による全画面平滑化・画面ボカシ用フィルターとして実装。

### ③ GaussianFilter (5点) - 【実装済み】
* **ゲーム作品での利用**: ガウス分布の重み付け係数を用いた高品質画面ブラー。ブルーム（Bloom）パスの下処理や背景被写界深度表現として機能。

### ④ LuminanceBasedOutline (5点) - 【実装済み】
* **ゲーム作品での利用**: 画面の輝度（明るさ）バッファにSobelフィルタを適用し、明暗差からくっきりとした輪郭線を抽出・描画。

### ⑤ DepthBasedOutline (8点) - 【実装済み】
* **ゲーム作品での利用**: 深度バッファ（Depth Texture）にSobelフィルタを適用し、3Dオブジェクトの幾何学的な境界・立体エッジを正確に抽出して描画。

### ⑥ Radial Blur (5点) - 【実装済み】
* **ゲーム作品での利用**: 画面中央を中心とした放射状モーションブラー。機体のブースト加速時や超高速飛行時のスピード感演出に使用。

### ⑦ Dissolve (4点) - 【実装済み】
* **ゲーム作品での利用**: ノイズマスクテクスチャの閾値判定による焼き切り演出。ゲームオーバー時の画面解体演出や敵・エフェクトの消滅表現に使用。

### ⑧ Random (4点) - 【実装済み】
* **ゲーム作品での利用**: 擬似乱数を用いた画面グレインノイズ。ナイトビジョン（NVD）モード時の暗視カメラノイズ表現やCRTノイズ演出として適用。

### ⑨ その他 - 【実装済み】
* **Bloom**: 高輝度成分の抽出＋ブラー＋加算合成によるバーニア噴射、爆発、太陽光の発光演出。
* **Chromatic Aberration (色収差)**: 被弾時の衝撃・爆発インパルス・ゲームオーバー演出における色ズレ効果。
* **Lens Distortion (レンズ歪み)**: ナイトビジョン時の暗視スコープ魚眼歪み表現。
* **ScanLine (走査線)**: モニター・ナイトビジョンHUDの走査線演出。
* **LightAmp (光量増幅)**: 暗所での動的露出ゲイン増幅。
* **Kawase Blur (川瀬式ブラー)**: 高速・広領域マルチパスブラー。
* **Color Isolation (パートカラー)**: 特定抽出色以外をモノクロ化する視覚演出。
