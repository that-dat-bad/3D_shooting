# タイトル画面用 3D背景モデル 配置ガイド

タイトルシーン（`TitleScene`）では以下の3つのシチュエーション用モデルを自動認識・描画します。
Blender等でモデリングしたモデルをこのフォルダ（`Resources/models/title/`）にエクスポートしてください。
モデルファイルが存在しない場合でもゲームはクラッシュせず、機体・スカイボックス・ライティングのみで動作します。

---

## 1. 格納庫（ハンガー）
- **ファイル名**: `hangar.obj` または `hangar.gltf`
- **推奨パス**: `Resources/models/title/hangar.obj`
- **原点 (0, 0, 0)**: 機体の駐機位置（床面 Y = 0.0）
- **推奨要素**:
  - コンクリート床（黄色のタキシングライン、駐機枠）
  - 奥の格納庫シャッター（隙間から外光）
  - 天井鉄骨トラス、配管パイプ、キャットウォーク
  - 投光器、消火器、作業台などの小物

## 2. 空母の飛行甲板（フライトデッキ）
- **ファイル名**: `carrier_deck.obj` または `carrier_deck.gltf`
- **推奨パス**: `Resources/models/title/carrier_deck.obj`
- **原点 (0, 0, 0)**: 機体の発艦スタンバイ位置（甲板面 Y = 0.0）
  - ※ シーン全体では海面（Y=0）から甲板（Y=+18m）の位置に配置されます。
- **推奨要素**:
  - ノンスリップ塗装の甲板、カタパルト溝
  - ジェットブラストディフレクター（JBD、斜めに上がった遮蔽板）
  - 艦橋（アイランド）の壁面、着艦ワイヤー

## 3. 墜落済みの森（Crashed Forest）
- **ファイル名**: `crash_forest.obj` または `crash_forest.gltf`
- **推奨パス**: `Resources/models/title/crash_forest.obj`
- **原点 (0, 0, 0)**: 機体の胴体墜落地点（地面 Y = 0.0）
- **推奨要素**:
  - 抉れた茶色い土のクレーター溝、雪や落ち葉
  - なぎ倒された木々、折れた幹、周囲を取り囲む鬱蒼とした針葉樹
  - 散乱した外板パネルや土煙の跡
  - ※ 機体は自動的に左翼がもぎ取れ、後方に千切れた翼が突き刺さる演出が入っています。

---

## 共通エクスポート仕様
- **スケール**: 1 Unit = 1m（戦闘機 `m21.gltf` の全長 約15m と同じ比率）
- **軸設定**:
  - OBJ: Forward = -Z, Up = Y
  - glTF: Blender標準（+Y Up, -Z Forward）
- **テクスチャ**: BaseColor（および法線マップ `_normal` があれば配置）
